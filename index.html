Rounded by rule, not by default.

Vigil is a free variable typeface by Keno Vigil — a geometric grotesk with a large x-height, a double-story a and a single-story g. Rounding is applied by rule — most at exposed terminals (C G S c e s, the arms of E F T, the feet of K and z), then a smaller, even radius at structural corners and on the stems of l, L, 1 and I, which keep enough edge to stay apart. At 16px it reads as a clean sans. At 96px the softness becomes the signature.

Text, 16px

Type is the interface. A body face earns its place in the first paragraph, not the first headline. Vigil keeps its counters open and its spacing even at small sizes, so long passages stay quiet and the rounding never announces itself. Set it at 16 over 24 with a measure near sixty-five characters, and the page reads like it was never designed at all — which is the point.

Questions, answered.

Is Vigil free for commercial use?

Yes. Vigil is released under the SIL Open Font License 1.1, so you can use it in commercial work, embed it in apps and websites, and sell products set in it. There is no cost, no account, and no attribution required in your designs.

What is Vigil based on?

Vigil is derived from Figtree, Erik Kennedy's open-source geometric sans, under the SIL Open Font License. Figtree supplies the skeleton. The rounding rules, the outline style and the finished curves are Vigil's own.

How many weights does Vigil have?

Eight weights, from ExtraLight 200 to Black 900, each with a matching italic. There is also a separate Vigil Outline style in roman and italic. One variable font file covers the whole 200 to 900 axis.

Can I use Vigil in a logo?

Yes. The SIL Open Font License places no restriction on what you set in the typeface, logos and wordmarks included. The one thing the license forbids is selling the font files on their own.

Which languages does Vigil support?

Vigil covers Latin Extended, which includes Western and Central European languages such as English, Spanish, French, German, Polish, Czech and Turkish. Kerning runs throughout, alongside tabular figures, fractions, superscripts and subscripts.

How do I self-host Vigil on a website?

Download the zip, copy the two variable WOFF2 files to your server, and add the two @font-face rules from the download section below. One file covers all eight weights. Static WOFF2 and TTF files are included for older browsers.

Is there a matching icon set?

Yes. Vigil Icons is a companion set of 111 icons drawn on the same 24px grid as the type, and every one of them is free with no email — the same terms as the font. SVG, PNG, sticker packs and Slack and Discord emoji.

Using it takes about a minute.

Three ways in, depending on what you are. Every snippet below is real and copyable — nothing here needs an account.

Designers

Install it like any other font.

Download, unzip, select the 16 Vigil-*.ttf files sitting right there in the folder, double-click, Install. Nothing to dig through — they are at the top level on purpose. On Windows, extract the zip first; it will not install fonts from inside one. There is a Read me first.txt in there if anything goes sideways. Figma and Sketch read your installed fonts — quit and reopen Figma’s desktop app and Vigil appears in the picker. On Figma in the browser you need their font installer running.

Developers

One line, no build step.

Served with Access-Control-Allow-Origin, so it works from your domain without downloading anything.

HTML
<link rel="stylesheet" href="https://www.vigilfont.com/vigil.css">
CSS — self-hosted, or paste as-is
@font-face {
  font-family: "Vigil";
  src: url("https://www.vigilfont.com/fonts/Vigil-wght-.woff2") format("woff2");
  font-weight: 200 900;
  font-display: swap;
}
@font-face {
  font-family: "Vigil";
  src: url("https://www.vigilfont.com/fonts/Vigil-Italic-wght-.woff2") format("woff2");
  font-weight: 200 900;
  font-style: italic;
  font-display: swap;
}

One variable axis, so font-weight: 437 is a real value, not a rounding error.

Writers

Slides, decks, documents.

Mac — unzip, select the TTFs, double-click, Install Font. Vigil is then in Keynote, Pages, Word and Canva’s desktop app. Windows — select the TTFs, right-click, Install.

Canva — Brand Kit → Brand Fonts → Upload. Note that font upload is a Canva Pro feature; the desktop app reads your installed fonts for free instead.

Google Docs cannot do it. Docs only loads fonts from Google’s own library, so no uploaded font works there — Vigil included. That is a Docs limitation, not a licensing one.
